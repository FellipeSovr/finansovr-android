Primeira versão do Finansovr como app Android.

- Voltar pelo gesto da borda, com prévia: fecha um nível por vez e, no Painel, avisa antes de sair.
- Compartilhar PDFs e imagens de outros apps direto para a pasta "A importar".
- O app avisa quando houver versão nova e instala pelo próprio Android.
- Abre com os últimos dados mesmo sem internet e avisa no topo.
- Conectar à planilha pelo QR code (ou pelo código), com uma chave só deste celular.
- Vibração pelo motor do celular, com chave para desligar em Ajustes › Aplicativo.
